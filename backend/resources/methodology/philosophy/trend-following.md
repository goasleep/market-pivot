# 核心观点

当资产形成持续趋势时，顺势研究通常比单点预测更适合短中期交易决策。动量
可以作为候选筛选和持有确认依据，但不能保证未来继续上涨。

# 适用条件

- 标的流动性足够，交易成本可控
- 市场存在持续的方向性行情
- 交易周期允许等待趋势确认
- 研究同时考虑相对基准表现

# 失效条件

- 震荡和快速反转市场
- 价格信号与成交量、相对强弱明显背离
- 交易成本或滑点吞噬预期收益

# 可检验假设

- 价格位于 MA20 和 MA60 之上时，未来 10 至 20 个交易日的风险收益是否改善
- 相对基准持续走强的 ETF 是否具有稳定的短中期超额表现

# 可转化规则

趋势观点只能转化为明确的入场、退出和仓位条件，并必须经过含手续费、滑点
和样本外区间的回测。
