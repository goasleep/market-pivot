# 经验总结

高位买入往往不是因为缺少观点，而是因为缺少预先写好的入场条件、仓位上限
和失效条件。复盘时应区分“判断错误”和“执行偏离规则”。

# 适用条件

- 保存当时的行情快照、理由、仓位和风险计划
- 复盘结论可以回到具体的交易记录

# 失效条件

- 只根据一次成功或失败交易总结规律
- 使用事后信息改写当时的判断
- 把别人的成功经验当作当前标的的事实证据

# 可检验问题

- 用户是否在大涨后才首次建立仓位
- 偏离交易规则的订单是否带来更差的后续回撤
- 连续亏损后是否出现提高仓位或缩短持有周期的行为
